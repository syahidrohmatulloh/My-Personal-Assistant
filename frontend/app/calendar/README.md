# Calendar MVP

This page displays confirmed local events and synced Google Calendar events as a compact mini timeline.

Pending Calendar suggestions are handled in chat and are not shown as user-facing candidate cards.

Timeline UX features:
- compact row-based agenda
- continuous left timeline spine
- subtle mobile-optimized time column
- Google/local dot indicators
- dashed smart free-time rows
- compact micro-warning for tight or overlapping schedules
- wrapped event titles on mobile so locations/details are readable
- minimal mobile Google link
- Calendar header reuses the same identity-owned label hook used by Journal, Goals, and People

- Calendar appears in the main sidebar navigation with a contextual badge for pending scheduling actions or tight/overlapping events.

- Back to chat uses the shared BackToLastChat behavior, so it returns to the last active chat instead of always opening /chat.
